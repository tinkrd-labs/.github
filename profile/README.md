## What is tinkrd-labs?

tinkrd-labs is an open-source organisation built around making developer workflows better. Every project here is focused on solving a real problem — nothing built for the sake of it.

It started with Git tooling, but the scope goes further than that. Anything that makes day-to-day development faster, cleaner, or less frustrating belongs here.

We think good tools should be:

- Simple to pick up
- Clear about what they do
- Small in scope, solid in execution
- Useful whether you're new to development or have been doing it for years


## Our philosophy

> Useful tools, built right. No bloat, no noise.

tinkrd-labs isn't about shipping as much as possible.

It's about building things that are actually worth using — tools that are well thought out, properly documented, and maintained over time.

## Get involved

tinkrd-labs is open to contributions across all projects.

You can:

- Explore the projects
- Report issues
- Suggest ideas
- Open a pull request
- Help improve documentation
